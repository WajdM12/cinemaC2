# نادي السينما - جامعة الملك سعود (التصميم الأحدث)

التصميم الأحدث: خلفية كريمية، شريط فيلم مثقب، شعار النادي في الهيرو على خلفية سوداء، وأهداف النادي في شبكة تحريرية باللون البرغندي (`#5A1024`).

## التشغيل محلياً
    python3 -m http.server 8000
ثم افتح http://localhost:8000

## الملفات
- `index.html`: الصفحة الرئيسية.
- `styles.css`: التصميم والخطوط (Amiri للعناوين، IBM Plex Sans Arabic للنص، Bebas Neue للأرقام).
- `script.js`: القائمة للجوال، حالة الترويسة عند التمرير، وإبراز الرابط النشط.
- `assets/logo.png`: شعار النادي كما هو بدون تعديل.

## النشر
يعمل كموقع ثابت على GitHub Pages أو Netlify أو Cloudflare Pages.
